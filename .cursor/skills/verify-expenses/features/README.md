# Feature map: ExpenseManager

Interactive C++17 CLI expense tracker (menu on stdin/stdout).

- Add expense: description, amount, YYYY-MM-DD date, category, Cash/Credit type.
- View all: indexed table of every expense.
- Delete by index.
- Save/load: CSV round-trip at data/expenses.csv (5 columns, quoted fields).
- Summarize: by day, month, year, or date range; monthly summary verified by verify.py.
